Welcome to Polly the Polling Bots User and Installation Guide!

About The Bot:
This bot is designed for users to create polls using a command such as /poll or !poll with a question and 2-10 answer options using buttons on discord servers, which can then be responded to by other server members and once the poll closes, the results can be seen listed as a percentage of each option.
